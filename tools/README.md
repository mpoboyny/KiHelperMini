safe_ldd is a static dependency analyzer.
The call without parameters will show usage
An example call: ./safe_ldd ../KiHelperMini

KiHelperMiniRunner.sh is run helper
Sometimes, if safe_ldd show no problems, KiHelperMini do not start with an error, like this: so not found
Try it: ~/KiHelperMini$ tools/KiHelperMiniRunner.sh
