wxSocketInitializer Class Reference

#include <wx/socket.h>

Detailed Description

Class initializing sockets in its ctor and shutting them down in its dtor.

This is a simple RAII wrapper around wxSocketBase::Initialize() and wxSocketBase::Shutdown().
