◆ wxWebViewBrowsingDataTypes

enum wxWebViewBrowsingDataTypes

Types of browsing data that can be cleared.

Note that different constants can be combined using the bitwise OR operator and that wxWEBVIEW_BROWSING_DATA_ALL is a shorthand for specifying all of them.

Since
3.3.0
Enumerator
wxWEBVIEW_BROWSING_DATA_COOKIES 

All stored and session cookies.

wxWEBVIEW_BROWSING_DATA_CACHE 

Cached data from disk and memory.

wxWEBVIEW_BROWSING_DATA_DOM_STORAGE 

All DOM Storage: File Systems, Indexed DB, Local Storage, Web SQL, Cache Storage.

wxWEBVIEW_BROWSING_DATA_OTHER 

Other browsing data like history, settings, auto fill, passwords, etc.

wxWEBVIEW_BROWSING_DATA_ALL 

All browsing data, including data corresponding to all the other constants.
