Detailed Description

File system handler for "data" URI scheme (RFC 2397).

URI syntax: "data:[<mediatype>][;base64],<data>".

The handler makes the data, included (encoded) into URI, available for components that use the wxFileSystem infrastructure.

To make available for usage it should be registered somewhere within an initialization procedure:

wxFileSystem::AddHandler(new wxDataSchemeFSHandler);
