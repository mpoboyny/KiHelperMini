◆ wxIsRunningUnderWine()

bool wxIsRunningUnderWine ( wxVersionInfo *  ver = nullptr)

Returns true only for MSW programs running under Wine.

Return true if the program is running under Wine and not a "native" MSW system.

Parameters
verIf non-null and the program is executing under Wine, it is filled with Wine version information (this output parameter is only available in wxWidgets 3.3.0 and later).
Returns
true if running under Wine, false otherwise.

3.1.6
