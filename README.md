KiHelperMini

It is a program for software developer or AI-enthusiastic users. KI is the German abbreviation for AI in English.

It is an Utility, that help you work with local AI models.
I wrote it for me. It will be good if the program helps someone else.

It is alpha version. Only Linux work now. MSWindows support coming soon.

KiHelperMini_DebianTrixie_x64.7z is compiled binary. I have test it with debian-live-13.6.0-amd64-xfce.iso in KVM. 
After installing of CMake, have always work. If you have a problems with run of KiHelperMini, take a look in tools folder.

To build it by itself, please read HowToBuild.md first.

Build with wxWidgets and lama.cpp.
